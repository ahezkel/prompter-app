# פרומפטר חכם לאנדרואיד (בניית APK אוטומטית ב-GitHub)

## איך מפיקים את קובץ ה-APK?
1. פתח ריפוזיטורי חדש ב-GitHub (למשל `prompter-app`).
2. העלה אליו את כל הקבצים מתוך התיקייה הזו (כולל התיקייה הנסתרת `.github`).
3. היכנס ללשונית **Actions** בריפוזיטורי שלך ב-GitHub — תראה שהתהליך **Build Android APK** רץ אוטומטית (2–3 דקות).
4. בסיום הריצה, לחץ על הריצה והורד למטה את הקובץ **`prompter-studio-apk`** (בתוכו נמצא `app-debug.apk`).
5. העבר את `app-debug.apk` לטלפון האנדרואיד והתקן!
